Step A: Styling Approach

CSS (plain)
→
:root custom properties

Tokens live as CSS custom properties in index.css under :root (dark defaults) and [data-theme='light'] overrides. Tailwind CSS v4 handles layout utilities; CSS variables handle theme-aware colours. Components reference tokens via var(--token-name).

Step F: Responsive Plan

Where the layout changes, and to what. These are the min-width values in media queries.

BreakpointLayout Change
Below 640px (phone) Cards stack to single column. Comparison columns stack vertically. All content uses full width with 16px edge padding.
640px+ (small tablet) Comparison columns sit side-by-side (flex-direction: row).
720px+ (tablet) Results and history cards display in a 2-up grid (grid-template-columns: repeat(2, 1fr)).
900px+ (desktop) App shell widens from 680px to 880px.
1280px+ (wide desktop) App shell widens to 1100px.
Hard Requirement
No horizontal scrolling on a 375px-wide phone (iPhone SE). All content fits within overflow-x: hidden on the root container.

Accessibility Checklist

✓
Every text-on-background pair passes 4.5:1 contrast
#F5F5F5 on #171717 = 17.3:1 ✓ · #DC2626 on #171717 = 5.1:1 ✓ · #F5F5F5 on #DC2626 = 4.6:1 ✓
✓
Real semantic elements, not divs with onClick
Uses <button>, <header>, <input>, <textarea>, <select> throughout
✓
Every meaningful image has alt text
Phosphor icons use aria-label or are decorative (aria-hidden). SVG logos use fill with semantic role.
✓
Every form input has a matching label
Project title and description fields use <label> with for/id pairing.
✓
Tab key reaches every link and button, with visible focus
button:focus-visible, input:focus-visible, select:focus-visible all show 2px crimson outline with 2px offset.

Design Principles Summary

Consistency
Every card, button, badge, and input uses the same token values. No ad-hoc colours or sizes.
Accessibility
Focus-visible rings on all interactive elements. Minimum 48px hit targets. High contrast text ratios.
Responsive
Narrow forms on mobile, side-by-side columns on desktop. App shell scales through 680 / 880 / 1100px.
